## Spring26_B1_Intentional_Design

Your job is to do the following

    Write 2 functional requirements
    write 2 non-functional requirements
    write the contracts for the provided java file.

Your requirements need to be written in the src/Requirements.txt file. Make sure you read the instructions in the Requiremnets.txt
file so you know what you're writing the requirements on. For the contracts, you only need to write the ones that have 
provided javadoc comment associated with it. That means you're writing just the 4 contracts!



When you complete the benchmark, you'll need to submit to Gradescope. I only want the following files:

    Cat.java
    Requirements.txt

do NOT submit anything other than these two files. If you are taking the benchmark with SAS, use this link: https://www.gradescope.com/courses/1224352/assignments/7604120

If you are taking the benchmark with class at your normal time, use this link: https://www.gradescope.com/courses/1224352/assignments/7604129
